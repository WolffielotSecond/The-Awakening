## 二、序章流程（按文档第 18 页）

1. 开屏是混乱的画面 → 点“新游戏” → 坠落效果 → 姐姐四仰八叉躺在地上醒来
2. **家**：温馨的样子；姐姐一边喊妹妹一边自由探索，能搜到一些偏异常的线索（文本 / 可收集物）
3. 家门锁着，必须进**妹妹房间拿到日记本**才能出门。拿日记本之前捡文本只能预览，拿到后才能收集
4. 姐姐自言自语“妹妹可能出门了” → 出门到**单元楼道**（一楼）
5. 出单元门：左边被绿化挡住，只能往右；越往右天越暗、没有人、有阴风
6. 走到**下沉广场水池**，看到一滩血，姐姐被吓到 → 水池里冒出**眼睛怪**开始追
7. 往左逃回单元楼，冲进家门 → 里面变成**医院**（门和墙还是家的，左边是医院）
8. 两边房间都变成白墙；往左走，原来妹妹的房间变成**病房**，从进门起一直有滴滴声
9. 切片结束（第一章从敲病房门开始）

## 五、建议的制作顺序（程序侧）

1. **收尾**：背包改动 PIE 自测并提交；在编辑器里确认 `Persistent_Level` 现有内容
2. **敌人基类 + 眼睛怪追逐**（序章唯一的大块新代码；基类按完整战斗系统的需要设计），包括碰到即死和 OnWorldReset 复原
3. **家 → 医院的空间切换** + 水池事件 Director 接线
4. 主菜单、默认地图 / GameMode、结束画面
5. 教程提示卡片
6. 配合策划和美术：灰盒关卡、文本和独白录入、Wwise 环境音
7. 全流程 PIE 走一遍

完整战斗系统和第一章的内容（潜行、终端破解、钢管 QTE 接入、黑影对话）可以在序章跑通后并行开始。

## 七、2026-10-27 新版文档的变更（对比上一版）

文字对比只有第 3 节“战斗设计”有实质变化，其余都是措辞：
- 翻滚：手柄键位定为**右扳机**。
- “体术”改为“空手搏斗与体术”：空手长按 Q / LB 防御（双臂护头），短按弹反；拿到武器前体术是唯一的进攻手段；**被怪物发现后自动进入格斗预备姿势**。
- 潜行：手柄定为**左扳机**；潜行中跑酷改为“站起→跑酷→再蹲下”（不再要专门的潜行跑酷动画）；潜行中攻击定为“直接取消下蹲开打”（上一版是两种思路待选）。
- 新增**刺杀**（团队已定不进切片）：拿到破解器后，对没发现你的敌人从背后按左键 / A / □ 暗杀；有武器后可以用武器刺杀；站立或下蹲都能刺杀；之后可以用技能降低刺杀噪音。
- 背包、外套、拾取、文本、日记本、扫描、破解器部分**没有变化**，已完成的背包改动不受影响。
