# 背包系统：现有代码 vs 新版设计文档

对照范围：新版《The Awakening Game Overview》PDF 第 4–13 页（扫描、背包、可收集物品、普通物品、剧情物品、外套设定）与 `Source/The_Awakening/Inventory`、`UI/Inventory`、`UI/Pickup`、角色的背包/拾取逻辑。只读检查，未改代码。

## 一、缺失（文档有，代码没有）

| # | 文档要求 | 代码现状 |
|---|---|---|
| 1 | **外套更换界面**：与地图上的衣服挂交互后打开，左边是待换外套及其口袋，右边是玩家当前穿戴；拖拽交换外套，拖动物品在外套口袋和玩家口袋之间转移；界面时停 + 无敌 | 完全没有。`EquipOuter` / `UnequipOuter` 在 C++ 里没有任何调用方，Content 里也没有衣服挂相关资产 |
| 2 | **衣服挂 Actor**：有外套 / 空衣服挂两种外观，换完后地图上的模型刷新成被换下的外套；外套口袋里的物品跟着外套留在衣服挂上 | 没有 |
| 3 | **外套增益 / 专属技能**（白大褂加最大生命值、伪装成衣服；卫衣帽子伪装成小怪），穿上生效、脱下失效 | `UTAClothingDefinition` 没有增益或技能字段，也没有生效/失效的钩子 |
| 4 | **背包里的外套装备格**显示当前外套 | `OuterEquipSlot` 一直 `SetEmpty()`，注释写着“后续可显示外套图标” |
| 5 | **迷你背包占用提示**（类 Arc Raiders）：拾取时在 Q 版小人右侧显示，空格是空心圆角方块，满格是白色实心，未满的堆叠按 数量/上限 显示灰度；被占用的格子闪两下；显示 4 秒，再次拾取刷新计时；排版与背包一致 | 没有任何对应控件 |
| 6 | **“背包已满”提示**显示在迷你背包上方 | 只有拾取列表里的通用 `Pickup_Failed` 文字（`TAPickupPanelWidget`） |
| 7 | **穿外套后默认口袋的排版会调整** | 内衬口袋固定不变，外套口袋只是追加在后面 |
| 8 | **背包里的技能面板**（5.2 节，只能重新分配技能和护符） | 技能页签存在，但只是占位文字 `Text_SkillsPlaceholder` |

## 二、冲突（两边都有，但行为不一样）

| # | 文档 | 代码 | 影响 |
|---|---|---|---|
| 1 | 换外套时，**衣服挂上那件外套口袋里的物品跟着它一起穿上** | `EquipOuter(UTAClothingDefinition*)` 只接收定义，用空口袋新建实例，衣服挂上那件的物品会丢失 | 做外套更换界面时需要改成传入 `FTAClothingInstance` |
| 2 | 已经穿着外套时可以**直接交换**（白大褂 ↔ 卫衣） | `EquipOuter` 在已有外套时直接 `return false` | 需要加一个交换接口，或者由界面先卸再装 |
| 3 | 口袋按**形状**定义：白大褂 3 个 1x2，卫衣一个 2x4 加一个 2x2 帽子 | `FTAPocketDef` 只有 `SlotCount` + 摆放方向；`TAClothingPanelWidget` 统一排成两列（左右侧）或两行（上下侧） | 2x4、2x2 这类形状无法准确表达，迷你背包也要复用这份排版 |
| 4 | 普通物品的出售价 `Value` 是 **float** | `int32 Value` | 小问题，确认一下代币是否需要小数 |
| 5 | 拾取提示里 3D 模型旋转“如每秒 360 度” | `ModelRotationSpeed = 180.f` | 文档写的是“例如”，可以在 WBP 里调 |

## 三、多出（代码有，文档没写）

- 物品类型里有 **武器 + 耐久度**（`ETAItemType::Weapon`、`FTAInventorySlot::Durability`、`WeaponDamage`），还有 **宝物 / 消耗品 / 技能书 / 货币**。文档只把物品分成“普通物品 / 剧情物品”。
- **手动整理** `SortInventory()`（合并同类堆叠并排序），文档里没有这个功能。
- 卫衣**帽子**的“空着时可以戴在头上”，代码里没有对应概念（属于缺失第 3 条，这里只是提醒：帽子既是口袋又能戴，需要专门的数据结构）。

## 四、已经和文档一致的部分

- 左侧 4 个剧情格固定绑定（`StorySlotIndex` 0–3），不能拖动、丢弃；升级版通过 `UpgradesFrom` 原位替换（破解器 → 升级版破解器）。
- 没穿外套时默认一个口袋 2 格（`DA_Clothing_Inner_Default`，缺资产时兜底 2 格）。
- 打开背包时停；扫描中打开背包会先取消扫描，时停交给时间系统处理。
- 拖拽：放到空格就移动，同类就堆叠，放不下的剩余部分留在原格，不同类就交换。
- 交互选项：普通物品是「检视」+「丢弃」；可堆叠时改为「部分丢弃」+「拆分堆叠」；剧情物品中日记本是「查看内容」，其他剧情物品是「检视」。
- 丢弃落点：先试脚下，再从正前方起每 60° 一个方向；墙、高低差 > 30cm、夹角 > 45°、已有物品的位置都跳过；全都不行就提示“无法掉落”，物品留在原格。
- 拆分：数量 1 ~ 全部，只放进空格，不和其他堆叠合并；没有空格时选项置灰。
- 部分丢弃生成一个带数量的掉落物 Actor。
- 拾取时先补已有堆叠再放空格，能部分拾取（地上 5 个只装得下 2 个就捡 2 个，剩余留在地上）。
- `bCanSell` / `Value` 字段已经有了。
- 拾取提示 0.5s 滑入 / 4s 停留 / 0.5s 滑出，文本标题 1.85s → 0.3s 淡出淡入 → 正文前 20 字；提示期间按背包键进入快速查看（物品进检视，日记本进查看内容，文本直接翻到对应页）。
- 存档按格子位置保存内衬、外套和剧情格。
