# 文本、背包操作、存档：PIE 检查清单

改动文本系统、背包交互菜单或存档后，在 PIE 里按这张表走一遍。说明见 [DocumentSystem.md](DocumentSystem.md)、[InventoryItemActions.md](InventoryItemActions.md)、[SaveSystem.md](SaveSystem.md)。

**准备**：关卡里放两份文本（`BP_Document` 或 `TAWorldDocument`，例如 `DA_Document_Sample01`、`DA_Document_67`）、一个日记本掉落物 `BP_WorldItem_Diary`、几个可堆叠和不可堆叠的物品、一个复活点。开始前 `TASaveDelete`、`TADocReset`。键鼠和手柄各走一遍。

## 1. 没有日记本时拿起文本

| 操作 | 预期 |
|---|---|
| 走近文本 | 出现在拾取列表里，名称和图标正确（没图标时显示默认图标） |
| 扫描悬停文本 | 显示统一介绍（一张写满了字的纸） |
| 交互 | 播放拿起动作，场景模型在关键帧消失；时停，打开文本预览 |
| 文本预览：拖动 / 右摇杆 | 模型旋转；上下可无限翻转，轴不随左右旋转改变 |
| 按「显示转译」 | 文本区整体居中、宽度为屏幕 1/3，标题居中、正文两端对齐（段落末行自然左对齐），无灰黑底框；模型和背景同步虚化变暗，底部按键提示保持清晰且可点击；正文可滚动，插图正常；再按一次淡出恢复模型检视。长文不越过底部提示；重复切换无残留暗幕 |
| 切换键鼠 / 手柄 | 手柄时隐藏光标并显示「旋转」提示；键鼠时显示光标、没有「旋转」提示 |
| 返回 | 普通文档淡出关闭，动画纸张折叠关闭；随后播放放下动作，模型重新出现；文本还在场景里，可以再拿起 |
| `TADocList` | 这份文本在「已读」里，不在「已收集」里 |
| 阅读中 `TAKill` | 预览被关掉，模型恢复；复活后 `TADocList` 里不再是已读 |

## 2. 日记本与收集

| 操作 | 预期 |
|---|---|
| 捡起日记本掉落物 | 进入剧情槽；右侧拾取提示滑入 |
| 交互文本 | 立即收集，场景文本消失；播放塞入日记本动作；拾取提示先显示标题，再换成正文前 20 个字 + `...` |
| 提示显示时按背包键 | 提示消失，日记本直接翻到这一页并打开文本预览；返回 → 日记本 → 背包 |
| 连续快速收集两份 | 第一条立刻滑出，第二条接着滑入 |
| 背包里日记本 → 交互菜单 → 查看内容 | 书从剧情格内日记图标的中心、大小开始，移动放大到中央，同时翻开；页码「1 / 2」；可以翻页，查看能打开文本预览 |
| 拾取日记/文本后首次按背包键快捷查看，再 Esc 关闭日记 | 无论此前是否打开过背包，书都合上并缩回左侧剧情栏内日记图标；更改分辨率/DPI 后仍对齐 |
| 在 IMC/UI 改绑下一页，再重新打开日记 | 新键执行翻页，旧键失效；短按、长按、松开和返回都由 Enhanced Input Action 处理 |
| 关掉日记本再打开 | 回到上次停留的那一页 |
| 首页短按 Q / LB / L1、末页短按 E / RB / R1 | 停留当前页，不循环，无多余翻页动画；首页左侧无末页文档 |
| 查看底部提示并切换键鼠/Xbox/PlayStation | 显示两条长按首页/末页说明；图标跟随当前设备和 IMC 改键，0/1 份时隐藏翻页相关提示 |
| 长按 Q / LB / L1 或 E / RB / R1 超过 0.65 秒 | 跳到首页或末页；持续按住不重复触发；短按松开不触发跳页 |
| 新开一次 PIE，捡日记→任意文本→首次按背包键快捷查看→返回 | 首次左页不变黑；再拾取并快捷查看也正常；分别在此前开过/没开过背包、收过/没收过其他文本时验证 |
| 只收集 0 / 1 份时 | 0 份显示空书；0 / 1 份不能翻页 |
| 收集 6767676767 后查看日记本 | 纸保持折叠并放在右侧书页上；点击后从书页位置取出放大并转向预览相机，然后展开；过渡中重复点击／返回无效 |
| 收集至少两份，向后翻页 | 当前右页文档跟随书页正面翻动，背面不可见，落页时无突然消失；左侧不留静置文档；下一份已在目标右页，随翻页逐渐露出，无结束后突然出现 |
| 向前翻页、连续来回翻 | 目标文档随翻动纸返回右侧，静置时左页不显示文档，无起落跳变、悬空或重影；动画中重复输入无效 |
| 分别打开 Sample01、Sample02、6767676767 | 三者使用同样的纸张模型/临时贴图和折叠动作；均可取出展开、旋转、折叠归位，转译标题和正文仍各不相同 |
| 点击右侧夹页 | 可打开当前文档，左侧不显示旧文档；鼠标旋转只影响抽出的文档，书本保持原位 |
| 旋转纸张后返回 | 平滑恢复朝向，折叠，再缩回书页位置；原处只显示一张纸，可继续翻页或再次查看 |
| 取出／展开期间强制关闭日记本 | 阅读器一起关闭，无残留纸张、输入占用或重复回调；再次打开仍为折叠姿态 |
| 不同分辨率／界面缩放查看纸张 | 取出与归位的位置对齐日记本中的纸，无跳变；展开时不自动缩放取景 |

## 3. 背包交互菜单

| 操作 | 预期 |
|---|---|
| 光标停在不可堆叠物品上按 `IA_ItemActions` | 光标旁弹出「检视 / 丢弃」，第一项已选中 |
| 可堆叠物品 | 「检视 / 部分丢弃 / 拆分堆叠」；背包满时「拆分堆叠」置灰，选中后按确定无反应 |
| 剧情物品 / 日记本 | 只有「检视」/「查看内容」 |
| 手柄上下键、光标悬停 | 选中项跟着变；确定键执行选中项 |
| 键鼠点菜单外的空白处 | 菜单关闭，后面的背包没有收到这次点击 |
| 检视 | 模型在中间，名称和介绍在下方，可旋转；返回回到背包 |
| 丢弃 | 物品出现在脚下；脚下已有物品时放到旁边；贴墙或无处可放时提示「当前位置无法掉落物品」，物品留在原格子 |
| 部分丢弃 / 拆分堆叠 | 弹数量窗口，「<」「>」和 `IA_QuantityDecrease/Increase` 调数量；拆分后新堆叠放进第一个空格，不与同类合并；取消什么都不变 |
| 掉在地上的物品 | 用物品的世界物品蓝图，能重新捡起 |

## 4. 存档

| 操作 | 预期 |
|---|---|
| 交互复活点 | 日志 `SaveGame ok`；`TASaveInfo` 显示关卡、复活点、文本数 |
| 收集新文本、改背包、改钱，然后 `TALoad` | 回到存档时的背包格子、钱、文本记录、日记本页码；角色出现在复活点 |
| 存档后才收集的文本 | 读档后又出现在场景里；存档前收集的不出现 |
| 在另一个关卡 `TALoad` | 先切回存档关卡再恢复 |
| `TASaveDelete` 后 `TALoad` | 日志提示没有存档，什么都不变 |

## 5. 剧情条件

| 操作 | 预期 |
|---|---|
| 分支选项加 `HasDocument`，填一份文本的 DocumentId | 收集前选项不满足，收集后满足 |
| `ReadDocument` | 没日记本时拿起读过一次即满足 |
| 存档 → `TADocReset` → `TALoad` | 条件结果和存档时一样 |
