# 1. 画风

- 材质类二游偏写实但不是高度photorealistic的画风，参照[《少女与学院城》](https://store.steampowered.com/app/3639650/Kotama_and_Academy_Citadel/)和[《绝区零》](https://zzz.mihoyo.com/)

- 画面偏冷色调，恐怖压抑风，可参考《小小梦魇》

- 角色和敌人全部采用2D关键帧动画的形式，以便更方便的展现动作细节，精度，张力，同样成本最低

- 场景为偏3D但是在与人物交互片段（跑酷）还是要与2D人物契合，如果这一块做好了反而能做出独特的风格

### 血条与死亡

- 游戏没有死亡惩罚，在解锁商人后角色死亡会被商人拖回存档点并且被商人复苏

- 玩家死亡后boss血不会回满

- 玩家在存档点（商人）处也无法坐火回满血（没有这个机制），但可以买血瓶回血

- 在玩家遇到商人前死掉（新手教程关）才会传送到设定好的回档点

### 扫描(更改过）

- 鼠标还是扫描时显示得了，鼠标悬停到物品和可交互终端上会显示信息

- 扫描时时间会暂停

- 玩家按下右键后可以对环境进行扫描，期间可收集物将会有亮点提示，怪物也会被红色高亮。在玩家按下右键后扫描最多持续10秒，玩家也可以松开右键主动取消扫描。在效果持续期间场景会变暗，耳边也会出现轰鸣声，声音随着效果即将结束变大

- 在通关第一章后玩家可以将扫描与破解器结合升级成破解扫描，玩家可以通过鼠标点击可被破解物品直接远程破解（也可以增加类似ram的设计一键破解防止重复玩小游戏）。效果持续期间场景会变暗但是泛红，周围也会有类似血丝的粒子效果。

### 背包

玩家可以更换衣服，衣服在地图上能拿到。不同的衣服有不同的加成或技能和口袋数，包括每个口袋格子数。

衣服类似塔科夫的包，里面的物品是跟着衣服走的，比方说玩家脱下衣服里面的东西也会跟着一起跟衣服脱下来，玩家可以通过跟衣服交互看衣服中的物品（不用学塔科夫读条搜寻）
