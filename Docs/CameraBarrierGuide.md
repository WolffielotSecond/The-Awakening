# 镜头挡墙 BP_CameraBarrier：地编使用教程

更新时间：2026-11-05。面向地图设计师。程序实现见 [RoomViewHandover.md](RoomViewHandover.md) 第 10 节。

## 1. 它是做什么的

镜头挡墙是一块**只挡摄像机、不挡玩家**的碰撞体，放在两个场景之间的隔断墙上（一般是区域最左侧或最右侧的墙）。

它的作用是：摄像机碰到挡墙就停住，过不去。因为隔断墙本身会挡住墙后的场景，所以只要摄像机不穿过墙，画面里就看不到下一个场景。

以“住宅最右侧的玄关，门外是楼道”为例：

- 在住宅里，用鼠标或右摇杆往右推镜头，摄像机碰到挡墙就推不动了。
- 玩家自己往右走到墙边时，摄像机也会被挡住。玩家可以继续走到门口，走向画面边缘，甚至暂时出画。
- 玩家从门里**完全走到挡墙另一侧**以后，摄像机会用很短的时间（默认 0.5 秒）平滑穿过墙，到达楼道这一侧，然后又被挡在楼道这一侧。
- 挡墙**两面都能挡**。玩家在哪一侧，摄像机就被挡在哪一侧，不需要指定属于哪个房间。
- 摄像机碰不到挡墙的时候（比如离墙很远），挡墙完全不起作用。

挡墙没有物理碰撞，不挡玩家，游戏里也看不见，不影响交互和声音。

## 2. 放置步骤

1. 在内容浏览器打开 `/Game/Blueprints/RoomView/`，把 **BP_CameraBarrier** 拖进关卡。不要直接拖 C++ 类 `Camera Barrier`。它要放在**隔断墙所在的那个关卡**里（子关卡也可以）。
2. **对齐墙**：把挡墙的红色盒子和隔断墙重合。盒子的 **X 方向**（红色箭头的方向）是**厚度**，要和墙的厚度方向一致。箭头朝哪一侧都可以，因为两面都会挡。
3. **调整大小**（Box Extent，或者用缩放）：
   - **厚度（X）**：和墙一样厚，或者稍微厚一点。玩家要完全走出这个厚度，摄像机才会换边。所以门框比较深的话，厚度可以盖住整个门框。
   - **宽度（Y）**：沿着镜头方向拉长，要**一直盖到摄像机所在的位置**（摄像机在房子前面几米远的地方）。往房子里面盖到后墙就够了。**摄像机不在盒子范围内时挡不住它。**
   - **高度（Z）**：从地板盖到比摄像机更高的地方。
4. 一般不用改参数。保存关卡，运行 PIE 检查（见第 4 节）。

## 3. 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| Camera Radius Cm | 10 | 摄像机离挡墙表面至少保持的距离，相当于摄像机的“半径”。看到墙的断面有闪烁时可以调大 |
| Cross Seconds | 0.5 | 玩家换到另一侧后，摄像机穿过墙用的时间。0 表示立即过去（会有跳切） |
| Barrier Enabled | 勾选 | 取消勾选后挡墙不起作用，可以用来临时对比效果 |
| Barrier Box（盒子） | 10 × 400 × 250 | 见第 2 节第 3 步。没有碰撞，游戏中不显示 |

## 4. 检查清单（PIE）

- [ ] 在房间里用鼠标或右摇杆往墙那边推到底：摄像机停在墙前，看不到隔壁。
- [ ] 贴着墙走到门口：摄像机在墙边停住，玩家走向画面边缘。
- [ ] 穿过门、完全走到另一侧：摄像机平滑穿过墙到新的一侧，不卡住、不瞬移。
- [ ] 站在门里来回走：摄像机不会来回穿墙。
- [ ] 往回推镜头（远离墙）：马上就有反应。

## 5. 常见问题

| 现象 | 原因和解决办法 |
|---|---|
| 摄像机直接穿过去了，挡墙没效果 | 盒子的宽度（Y）没有盖到摄像机的位置，或者高度（Z）比摄像机低；`Barrier Enabled` 没勾选 |
| 玩家已经过门了，摄像机还卡在原来那边 | 玩家还没有完全走出盒子的厚度（X）。把厚度改薄，或者检查盒子是否转歪了 |
| 摄像机穿墙时一下子跳过去 | `Cross Seconds` 是 0，改回 0.5 |
| 画面边缘、房子正面之外还露出隔壁一角 | 隔断墙没有延伸到房子正面，墙前面的空隙挡不住视线。可以把墙模型往前延伸，或者在当前房间的 `BP_RoomRegion` 的 `Blackout Room Ids` 里填上隔壁房间，让它变成黑场 |
| 摄像机在离墙很远的地方就停住了 | 盒子的厚度（X）拉得太厚，或者盒子转歪了，厚度方向没有对齐墙 |

## 6. 注意

- 关卡里只放 **BP_CameraBarrier**，不要放 C++ 类。
- 挡墙放在哪里由地图设计师决定，程序只维护功能本身。
- 过场镜头以后可能会临时关闭挡墙，这由程序处理，地编不需要特别设置。
